## 파일 저장소

`STORAGE_BACKEND` 로 고른다. 쓰는 쪽 코드는 어느 쪽이든 똑같다.

| 값 | 어디에 | 언제 |
|---|---|---|
| `local` (기본) | `LOCAL_STORAGE_DIR` 아래, `/files` 로 내보냄 | 혼자 개발할 때 |
| `azure` | Azure Blob Storage | 팀 공용 · 배포 |

Azure 쪽은 이렇게 되어 있다.

- 계정 `stdrawtale` (Korea Central, Standard_LRS, Hot)
- 컨테이너는 환경마다 하나 — `drawtale-dev` (팀 공용) · `drawtale-prod` (배포) · `models` (AI 모델)
- **컨테이너는 전부 비공개다.** 주소를 아는 것만으로는 열리지 않는다
- 파일 주소는 기한이 있는 SAS 로 내준다 (`AZURE_SAS_HOURS`, 기본 2시간).
  응답을 만들 때마다 새로 발급하므로 기한이 짧아도 된다
- DB 에 담는 경로(`uploads/{id}.png`, `results/{id}.mp3|mp4`)는 local 과 azure 가 같다

켜려면 `.env` 에 세 줄을 넣는다. 연결 문자열은 Backend 담당에게 받는다.

```
STORAGE_BACKEND=azure
AZURE_STORAGE_CONNECTION_STRING=...
AZURE_BLOB_CONTAINER=drawtale-dev
```

> 테스트는 `.env` 가 azure 로 맞춰져 있어도 언제나 임시 폴더를 쓴다 (`tests/conftest.py`).
> 공유 Blob 과 실제 OpenAI 를 건드리지 않는다.

## 로컬에서 실제 모델로 띄우기

1. drawtale-ai 를 먼저 띄운다 (`docker compose up -d`, 8001 · 8080).
2. `.env.example` 을 `.env` 로 복사하고 채운다. `.env` 는 git 에 올리지 않는다.
   - `DATABASE_URL=postgresql+psycopg://drawtale:drawtale@db:5432/drawtale`
   - `AI_SERVICE_URL=http://host.docker.internal:8001`, `AI_USE_MOCK=false`
   - 이야기·음성: `OPENAI_API_KEY`, `TTS_PROVIDER`, ElevenLabs 를 쓰면 `ELEVENLABS_API_KEY` · `ELEVENLABS_VOICE_ID`
   - 로그인: `KAKAO_CLIENT_ID/SECRET`, `GOOGLE_CLIENT_ID/SECRET`
3. `docker compose --profile app up -d`. `.env` 를 바꿨으면 컨테이너를 다시 띄워야 읽는다.

키는 채팅·문서·커밋에 붙이지 않는다. 비어 있어도 서비스는 돈다 (문장은 템플릿, 음성은 `null`).
